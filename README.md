# 🐦 Twitter Database Project

## Description
A MySQL database simulation of Twitter social media platform
built as the final SQL project to demonstrate advanced database skills.

## Features
- User registration with encrypted passwords (MD5)
- Personal profiles for each user
- Tweet creation and management
- Follow system between users
- Like system for tweets

## Tables
- Users (with encrypted passwords)
- Profiles
- Tweets
- Followers
- Likes

## Stored Procedures
- createAccount: adds new user and profile automatically
- User_Follow: manages following between users

## Skills Used
- MySQL
- Database Design
- ER Diagram
- Foreign Keys
- Stored Procedures
- MD5 Encryption
- DATETIME AUTO

## Tools
- MySQL Workbench
- WampServer
- Draw.io (ER Diagram)
